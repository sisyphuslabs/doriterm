# Terminal fonts

Cut from upstream releases with fontTools `pyftsubset` (`--flavor=woff2 --layout-features=*`). Each `@font-face` in
`../terminal-fonts.css` lists the characters the page takes from its file; every listed character is in the file
(Noto Sans Math's file holds 15 more that no range names).
