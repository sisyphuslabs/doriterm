### Machine mesh

- The machine order is one order for every device, whichever machine the app reaches the others through (#2531). It is
  kept on every machine and the newest arrangement wins, so a phone and a laptop list the machines the same way, and a
  reconnect that goes through another machine no longer reorders the list or puts that machine on top. Orders each
  machine kept before are merged into one the first time a device opens. Before you arrange them, machines are listed by
  name, and that first order is saved so every device starts from the same one. Settings no longer offers "Switch to this machine" or names the machine the app goes through, the status bar
  and the phone's Spaces status line name no machine when no terminal is in view, and a folded machine stays folded
  whichever machine the app reaches. The command palette's Hosts lists every machine.
