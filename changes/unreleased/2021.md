### Machine mesh

- A macOS or Linux member no longer dials its peers with herdr's Windows command line: `doriface-host connect` now
  exits 255 when it could not reach a member (no host running, a refusal, a line closed before the member spoke), the
  code herdr reads as "the connection itself failed", so it keeps the one reason instead of trying the member again as
  a Windows machine, a second try per failed redial that could pin a member as Windows until its core restarted. (#2019)
