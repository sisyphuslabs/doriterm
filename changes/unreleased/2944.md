### Machine mesh

- A device or machine asking to join now reaches you wherever you are: a card rises over the workspace on every device
  you use, with the name, the code to compare and what approving gives, and Approve or Deny answers it on the machine
  that opened the invite. Settings > Machines lists joins waiting on any machine of the mesh, not only on the one this
  app is attached to, where an invite opened on another machine used to wait unseen until it expired. (#2939)
