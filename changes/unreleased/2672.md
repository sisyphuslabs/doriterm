### Workspace

- A space the app makes for a terminal no tab shows (a lane an agent opens for new work) is now named after the work
  itself, its directory or the program it started, and only an existing Home space still takes them as before, instead
  of every such terminal landing in a generic Home. Two such directories that end the same way are told apart by
  their parent folder, as other folder spaces are. (#2670)
- A lane's tab (a command started with a name, as agents start their lanes) now reads the lane's name from the first
  tab on, and follows it when the lane is renamed. The label truncates with its whole title on hover. A bare shell
  keeps its place as a number, renamed or not, and a program's window title never names a tab. (#2670)

### Phone

- The Type field no longer draws a thin unlabeled bar down its right edge: the idle pill fits its one line exactly,
  where it used to be 2 px too short for it and so drew a scroll strip inside itself. (#2670)
