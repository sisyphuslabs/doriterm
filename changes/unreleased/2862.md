### Terminal

- A program can now ask to come back after a restart. Doriterm gives each terminal it starts its own OSC 7577 token,
  and a program that reports how to resume itself (the Program Resume Protocol) is started again in your shell after
  the core restarts or the machine reboots, once, with its arguments exactly as reported. Reports without the
  terminal's token are ignored, nothing runs as another user or as root, and `doriface-host --no-resume` turns it off.
  See docs/program-resume.md. (#2857)
