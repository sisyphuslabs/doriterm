### Host install

- On Linux, `bun apps/host/scripts/setup/cli.ts install` turns lingering on when it runs with no `USER` in its
  environment. It asked about a user called `unknown` there and left lingering off, so the host did not start at
  boot. (#2386)
- When it cannot turn lingering on, its warning names the command that works from an admin's account,
  `sudo loginctl enable-linger <user>`, as the installer and the docs do. (#2386)
