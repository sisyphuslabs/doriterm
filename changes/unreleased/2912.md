### Workspace

- Closing a just-opened tab before the machine has placed it in a space now waits until it is placed, with the tab's
  close button showing the close was taken, and then asks "Close space?" as closing a space's last tab always does,
  instead of ending the shell without asking. (#2911, #2913)
- A terminal ended or closed before the machine placed its tab no longer leaves a tab behind that waits for a terminal
  that is gone. (#2913)
