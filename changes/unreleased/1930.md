### Workspace

- The space keys work with the keyboard in a terminal, as herdr-app's do: Ctrl+1 to Ctrl+9 on a Mac, Alt+1 to Alt+9
  on Windows and Linux, show that space from inside a terminal as well as from the sidebar. A number with no space, or
  the space already in view, changes nothing and the key is not sent to the program; a program that needs one of these
  keys gets that row unbound in Settings, Keybindings. (#1925)
