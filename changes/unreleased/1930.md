### Keys

- With the keyboard in a terminal, every herdr-app shortcut now acts as it does in herdr-app: Ctrl+1-9 on a Mac and
  Alt+1-9 on Linux and Windows switch spaces, and Ctrl+V pastes an image on the clipboard as a file on the terminal's
  machine (with no image it sends Ctrl+V to the program, as before). Plain Ctrl+letter keys still go to the program.
