### Machine mesh

- A host whose `mesh.json` cannot be read now starts anyway, instead of not starting at all. It admits no member from that file and never writes over it. `mesh status` and the MCP mesh status say "mesh state unreadable: <file> (<why>); fix or remove it", and a mesh offer or join is refused with that reason before anything is dialed. Once the file is repaired (or removed), the running host picks it up without a restart. (#2951)
